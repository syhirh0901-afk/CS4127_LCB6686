# Discover Brunei – README

## Project Overview
Discover Brunei is a tourism website designed to showcase Brunei Darussalam's culture, attractions, heritage and travel information. This website was developed for a Web Development assignment.

## Website Pages
1. **Home** (`index.html`) – Introduction to Brunei.
2. **Discover Brunei** (`about.html`) – Culture, history and traditions.
3. **Attractions** (`attraction.html`) – Tourist destinations across four districts.
4. **Plan Your Visit** (`plan.html`) – Travel tips and information.
5. **Events** (`event.html`) – National celebrations and annual events.
6. **Contact** (`contact.html`) – Contact form and location details.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive navigation
- Interactive map and attraction filters
- Image cards and interactive sections
- Contact form

## How to Run
Open `index.html` in a web browser and navigate through the website.

## Disclaimer
This website is created for educational purposes only and is not an official tourism website.
